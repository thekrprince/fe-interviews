## Hacker Rank Assessment Que.

  1.  Problem: Filter Inappropriate Sentences
      You are given:
      An array of sentences (strings), and A list of inappropriate or "bad" words.
      Your task is to write a function that filters out and returns only the appropriate sentences, i.e., those that do not contain any inappropriate words.

      ```
      Input:
      sentences = ["I love coding", "This is stupid", "What a great day", "You are an IDIOT!"];
      badWords = ["stupid", "idiot"];

      Output:
      ["I love coding", "What a great day"]
      ```
